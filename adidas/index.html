아디다스 프로모션코드는 어디에 넣나요

입력하는 곳은 결제 단계의 프로모션 코드 칸 하나입니다. 계정 쿠폰은 같은 결제 단계에서 목록으로 고르고, 아울렛 할인은 장바구니에서 이미 반영됩니다.

  1. adiClub 계정으로 로그인

    adidas.co.kr 또는 adidas 앱에서 로그인합니다. 로그인하지 않으면 계정 쿠폰함이 결제 화면에 나오지 않습니다.

    비회원으로 장바구니를 채운 뒤 가입하면 웰컴 쿠폰 10%를 첫 주문에 바로 쓸 수 있습니다. 120,000원 주문이면 12,000원입니다.

  2. 상품 페이지에서 할인 표시 확인

    아울렛 또는 추가 할인 제품 구역의 상품이라면 25% 추가 할인 표시가 붙어 있는지 봅니다.

    같은 모델이라도 색상마다 표시가 다를 수 있습니다. 69,000원 아울렛 상품이면 표시 여부에 따라 17,250원 차이가 납니다.

  3. 장바구니에서 금액 확인

    추가 할인 표시 상품은 장바구니 금액에 할인이 들어갔는지 확인합니다. 반영이 안 됐다면 상품을 지우고 다시 담아 봅니다.

  4. 결제 단계에서 프로모션 코드 입력 또는 쿠폰 선택

    환영 이메일로 받은 개인별 할인코드는 프로모션 코드 칸에 넣고 적용을 누릅니다. 생일·레벨업 쿠폰은 같은 화면의 쿠폰 목록에서 고릅니다.

    쿠폰이 여러 장이면 할인율이 큰 쪽을 고릅니다. 정가 210,000원 주문에서 생일 15% 대신 레벨 4 레벨업 15%를 남겨 두고 생일 쿠폰을 쓰면, 다음 주문에서 또 31,500원을 아낄 몫이 남습니다.

  5. 최종 금액 확인 후 결제

    결제 버튼을 누르기 전 주문 요약에 할인 줄이 찍혔는지 봅니다.

    쿠폰은 결제 뒤에 소급되지 않습니다. 빠뜨린 채 결제하면 생일 쿠폰 20% 기준 150,000원 주문에서 30,000원을 그대로 놓칩니다.

  6. 주문 후 레벨 포인트 확인

    배송이 끝나면 계정에서 레벨 포인트가 쌓였는지 확인합니다. 다음 레벨에 닿으면 레벨업 쿠폰이 쿠폰함으로 들어옵니다.
